# 最终 RTX 5090 验收计划（未来唯一一次付费会话）

只允许一个 RTX 5090 On-Demand 订单、一个会话和一个明确费用上限（建议总上限 `$3.00`，仍受项目 `$0.70/h` 主机上限约束）。所有提示词、负面提示词、seed、档位和停止条件必须在租用前写入本目录；用户没有替换时，`TEST_PROMPTS.md` 的自动提示词就是有效输入。

顺序固定：验证 Blackwell Runtime → 只恢复一次 UltraReal → 中等图片 → 高图片 → 卸载图片模型 → 只恢复一次 Wan → 中等 720P 10 秒长视频（两段）→ 高 1080P-final 10 秒长视频（两段）→ 验证尾帧衔接与合并 → 同步全部媒体 → 自动取消 RTX 5090 → 两次只读确认资源为零。没有单独的短视频测试。

停止条件：Runtime/显卡不匹配、任一模型恢复校验失败、OOM/持续错误、输出尺寸或尾帧链不合格、费用接近上限、出现第二订单、SSH 端点不一致、媒体同步失败。停止时先保留媒体和证据，再取消唯一订单。

本计划不授权执行、不包含密钥、不会自动创建订单；实际执行必须由新的单次授权显式绑定 RTX 5090 和项目。
