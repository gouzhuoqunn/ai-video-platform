AI 图片视频平台启动说明

双击“启动平台.cmd”即可打开轻量本地控制窗口。它只绑定 127.0.0.1:3000，不需要管理员权限，也不会在启动时租用 GPU。

第一次启动：启动器会检查 Node/npm；如果本地测试账号尚未初始化，只运行一次 npm run local-lab:setup，然后启动 npm run dev:local。

日常使用：点击“启动平台”或“打开网页”。如果平台已经运行，启动器不会重复启动。点击“停止平台”只会停止本启动器记录的进程，不会结束其他 Node 程序。

所有真正的任务执行和 GPU 租用都必须在网页任务卡中手动点击“开始任务并租用显卡”。

故障排查：先点击“查看状态”；再查看 .secrets\launcher\platform.log。不要删除已完成媒体，不要同时启动第二个启动器。
